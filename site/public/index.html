01 · Spec sheet

What's in the box

Sources
Search by name, or paste a YouTube, SoundCloud or playlist link. Start a search with sc: to look on SoundCloud.
Shared queue
One per server. Shuffle, move, remove, go back, loop a track or the whole queue.
Eight effects
Bass boost, heavy bass, nightcore, vaporwave, treble, echo, 8D and karaoke. Applied live, mid-song.
Synced lyrics
One message that follows the song line by line, and keeps up when an effect speeds it up.
Three ways to control
/ commands, ! commands, and buttons on every Now Playing message.
Auto power-off
Leaves the voice channel after five minutes with nothing to play.

02 · Setup

Up and running in a minute

  1. 01

    Add it

    Press Add to Discord and pick your server. You need the Manage Server permission there.

  2. 02

    Join a voice channel

    The bot comes to whichever voice channel you are in when you ask for a song.

  3. 03

    Type /play

    A song name or a link. Suggestions show up while you type.

It asks to send messages and embeds, read message history, and connect, speak and use voice activity in voice channels. Nothing else.

04 · Troubleshooting

If something's off

E-01The bot joined, but I hear nothing

Check that you haven't muted it or turned its user volume down on your side (right-click the bot, then User Volume), and that /volume isn't at 0. If an effect sounds wrong, /reset removes it.

E-02A YouTube song fails and gets skipped

YouTube blocks some videos for bots. LoopifyBot says so in the channel and moves on to the next song. Try the same search on SoundCloud: /play sc: song name.

E-03The / commands don't show up

Give Discord a minute after adding the bot, then restart the Discord app. The ! commands work straight away.

E-04Does it keep any of my data?

No. There is no database: the queue lives in memory and is gone when the bot leaves. It reads the channel's messages only to spot ! commands. This website counts visits with Cloudflare Web Analytics, which sets no cookies.

E-05Is it free? Is it always on?

Free, with nothing behind a paywall. It runs on a self-hosted server, so it is on most of the time, but there is no uptime guarantee.

E-06Can I run my own copy?

Yes. It is open source under the MIT license, and the repository explains how to run it on your own machine, a home server or AWS.
